  required field, which edits that test (a stop-and-ask).
- 2026-11-25: A gap is a fail or unchecked line, as in T-0034's order; a section's own n/a
  and a not-assessed section have none. Alternative: count unchecked lines as half.
- 2026-11-25: The fact reads `<section> · <n> failing · <n> unchecked`, both counts always
  shown, section names as written (lowercase, as T-0034 shows them). Alternative: drop a
  zero count.
- 2026-11-25: The tests go in new files (`now-sections.test.ts`, `home-sections.e2e.ts`),
  since the moved repo needs T-0034's fixture before launch and `home.e2e.ts` launches the
  kit fixture in `beforeEach`. Alternative: new tests in `home.test.ts` and
  `home.e2e.ts`, which needs a second launch setup there.

- 2026-11-25: Merged origin/develop, then origin/card/T-0036 (no conflicts). BACKLOG.md,

  took them out. Alternative: restore develop's BACKLOG.md exactly.
- 2026-11-25: The rule lives in a helper `checklistSections` in `now.ts`, so `nowHealth`
  gains one line. Alternative: inline in `nowHealth`, which grows its complexity.
- 2026-11-25: The counts are coloured only when not zero (failing rose, unchecked amber, as
  Home's Needs you is), section name in medium weight. Alternative: plain text.
- 2026-11-25: The e2e launches both repos in one window (moved-repo, unmoved-repo), so the
  screenshot shows both cards side by side. Alternative: one repo per test.
