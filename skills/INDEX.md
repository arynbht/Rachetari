# Area skills

Plain folders, each unchanged from its upstream at the pinned commit (each folder's
content hash equals the pin's hash in Rivetari's manifest). A card names at most three
under its "Skills" heading; only those are read for that card.

"Used on a real task" means the skill was loaded at build on a BreathBand pilot task
(from the pilot ledgers), or loaded as an always-on skill there.

Notes from reading them (nothing installs hooks or overrides instructions; the install lines that fetch remote code are named below):

- The addyosmani skills link to sibling skills and `../../references/*.md` files that aren't here; those links are dead.
- `incremental-implementation` says to commit after each slice; `shipping-and-launch` has `git revert … && git push` inside a rollback-plan template.
- `native-writing` is its upstream repo root, so it carries `.github/`, `evals/` and a README with an `npx skills add …` install line for people.
- The legal skills' example companies and people are fictional; `dsar-processing` hard-codes an example fee. Their Python scripts use the standard library only.
- `animate` and `review-animations` open with a fixed reply before the first question.
- `constraint-driven-development` interviews the user (it says not to in CI, `/loop` or autonomous runs), then asks to add a line to `AGENTS.md` and `CLAUDE.md`, which here is a stop-and-ask. Its Step 4 table gives an install per dimension the user picks (`pip install`, `pipx install`, `brew install`, `npm i -D`), and its escalation level 2 wires a check script into the agent's post-edit hook and CI: installs and hooks are stop-and-ask here too. Its one red-flag line about `--no-verify` is a warning sign, not an instruction. It ships `scripts/quality-gate.mjs` (Node standard library only).
- `playwright-cli` suggests an unpinned global install (`npm install -g @playwright/cli@latest`) and an unpinned scaffolder (`npm init playwright@latest`), both parked. Its frontmatter pre-allows `Bash(npx playwright:*)`, and `npx` without `--no-install` downloads a missing package, so it must stay a plain folder a card reads and never be installed under `.claude/skills/`. Its `state-save` and cookie commands can write session tokens into files that must stay out of evidence and commits. "Never skip hooks" in `references/test-generation.md` is a rule against skipping.
